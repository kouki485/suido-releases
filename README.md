# suido-releases

水道使用開始申込みプログラムの、署名済み Linux 配布物を置くための公開リポジトリです。ソースコードは公開しません。

## 最新版

- マニフェスト: https://github.com/kouki485/suido-releases/releases/latest/download/manifest.json
- 配布アーカイブは、各 Release の Assets にあります。

プログラムの `./suido update` は、マニフェストの Ed25519 署名とアーカイブの SHA-256 を検証してから更新します。

## 注意

このリポジトリには、ソースコード、設定ファイル、認証情報、顧客データを置きません。
